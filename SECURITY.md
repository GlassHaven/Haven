# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately through GitHub Security Advisories rather than opening a public issue:

https://github.com/GlassHaven/Haven/security/advisories/new

Include the Haven version, affected protocol or component, reproduction steps, and the security impact. We review private advisory reports promptly and coordinate fixes before public disclosure.

## Supported Versions

Security fixes land on `main` and ship in the latest `5.94.x` release on GitHub Releases and F-Droid.
