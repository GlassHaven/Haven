# Classes loaded reflectively by fully-qualified name — Class.forName, JavaMail
# `mail.<proto>.class` properties, JNI lookups, etc. — and therefore MUST keep
# their original name through R8/minification.
#
# scripts/check-r8-kept-classes.sh asserts each is identity-mapped in the
# release build's mapping.txt. A rename (or removal) means a `-keep` rule in
# app/proguard-rules.pro is missing or broke — which ships a feature 100%
# broken in release builds while every *debug* test still passes (debug doesn't
# run R8). That is exactly how the email feature shipped briefly broken:
# getStore("imaps") threw NoSuchProviderException because R8 renamed
# com.sun.mail.imap.IMAPSSLStore -> s4.c (fixed in v5.59.45).
#
# Add a class here whenever you pull in a dependency that resolves classes by
# string name. One fully-qualified class name per line; #-comments and blank
# lines are ignored. (The JavaMail provider classes are *also* auto-derived from
# ImapMailClient's mail.<proto>.class properties, so the mail path self-checks.)

# JavaMail (com.sun.mail:android-mail) — IMAP/SMTP Store & Transport providers
com.sun.mail.imap.IMAPStore
com.sun.mail.imap.IMAPSSLStore
com.sun.mail.smtp.SMTPTransport
com.sun.mail.smtp.SMTPSSLTransport

# Reticulum (rns-core) — link/transport methods resolved by name
# (verified: Transport -> w4.q when the -keep rule is absent)
network.reticulum.transport.Transport

# Eternal Terminal (et-kotlin) — transport reflected
# (verified: EtTransport -> h5.b when the -keep rule is absent)
sh.haven.et.transport.EtTransport

# Reflected by HavenUiBridge.dumpUi (dump_haven_ui) — see app/proguard-rules.pro (#355).
androidx.compose.ui.platform.AndroidComposeView
androidx.compose.ui.semantics.SemanticsOwner

# SSH Authentication API — OpenKeychain and other external key providers (#487).
# The binder matches the interface descriptor by name, and the error Parcelable
# is unmarshalled by class name; renaming either breaks provider-held keys in
# release builds while every debug test still passes.
org.openintents.ssh.authentication.ISshAuthenticationService
org.openintents.ssh.authentication.SshAuthenticationApiError

# sshlib's Ed25519 JCE provider reads its own package name at install time
# (Ed25519Provider.class.getPackage().getName()). Repackaged into R8's root
# package, getPackage() returns null and the SSH handshake dies with an NPE
# right after ECDH_REPLY (#513). Listed here rather than trusted to the keep
# rule alone: it is a name-dependency like the rest, and this is the only
# check that would notice the rule being dropped.
org.connectbot.sshlib.crypto.ed25519.Ed25519Provider

# Opt-in root filesystem worker (#799) — launched via `/system/bin/app_process`
# by literal class name (`sh.haven.feature.sftp.root.RootFsDaemon`) with
# `CLASSPATH=<apk>`. Renaming breaks `Root (/)` in release builds only.
sh.haven.feature.sftp.root.RootFsDaemon
